# Razorpay Saathi - Frontend

The frontend for Razorpay Saathi is a modern Next.js application that provides a rich, interactive conversational commerce interface. It features a beautiful, dynamic layout where users can chat with the AI agent and instantly see generative UI components such as product cards and checkout widgets rendered in real-time.

## Features
- **Next.js App Router**: Fast and scalable React architecture.
- **Generative UI**: Agent responses can stream custom React components (Product Cards, Checkout Widgets) seamlessly into the chat.
- **Beautiful Design**: A premium, responsive interface featuring dynamic carousels, glassmorphism overlays, and smooth CSS animations.
- **Server-Sent Events (SSE)**: Real-time, streaming connection with the backend agents.

## Prerequisites
- Node.js 18+
- npm or yarn

## Installation

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

## Usage

Start the development server:
```bash
npm run dev
```

The web application will be available at `http://localhost:3000`. Ensure that the backend is also running on port 8000 for the AI integration to work properly.
